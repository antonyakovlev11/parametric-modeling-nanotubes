## Геометрия нанотрубок и выбор вариантов для моделирования

В групповом исследовании я участвовал в постановке задачи о взаимодействии нанотрубок с бензолом. В расчёте геометрии сравнил **18 структур** двух семейств. Диаметр трубки **(13, 0) — 1,018 нм**.

![Расчётные структуры](tube-structures.png)

*Структуры (12, 0), (13, 0) и (8, 8) длиной 2,5 нм. Геометрия построена из графеновой решётки без энергетической релаксации.*

### Мой вклад и расчёт геометрии

Я участвовал в обсуждении физической задачи и условий сравнения. Для анализа геометрии выбрал индексы `n = 10…18` и два семейства: `(n, 0)` и `(n, n)`.

`d = a / π × √(n² + nm + m²)`, где `a = 0,246 нм`.

![Диаметры двух семейств](tube-diameters.png)

При одинаковом n диаметр семейства «кресло» больше диаметра «зигзаг» в √3 раза. Для (12, 0), (13, 0), (14, 0) получено 0,940; 1,018; 1,096 нм.

![Выбор соседних вариантов](tube-near-one.png)

### Пример кода

```python
from nanotube_geometry import diameter

for n in [12, 13, 14]:
    print(f"({n}, 0): {diameter(n, 0):.3f} нм")
```

[nanotube_geometry.py](nanotube_geometry.py) проверяет индексы, рассчитывает два семейства и сохраняет `nanotube-diameters.csv`. Запуск: `python nanotube_geometry.py`. Готовая таблица: [diameters.csv](diameters.csv).

### Для каких аналитических задач это полезно

Формализация параметров, сравнение вариантов на одинаковой базе, проверка единиц и подготовка сетки сценариев. Расчёт помогает сократить набор вариантов для более дорогого моделирования.

### Следующий этап и границы результата

Я предложил сначала сравнить диаметры при фиксированных длине, температуре, модели взаимодействия и ориентации бензола. Затем — менять температуру при выбранной структуре и сохранять положение молекулы и энергию взаимодействия во времени.

Здесь выполнен геометрический расчёт. Молекулярная динамика и энергетическая устойчивость остаются следующим этапом. По одному диаметру я не устанавливаю порог вхождения бензола.
